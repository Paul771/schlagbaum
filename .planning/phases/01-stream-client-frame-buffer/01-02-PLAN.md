Build the capture path: the privratnik.net auth session manager, the ffmpeg subprocess stream client, and the reconnect/re-auth supervisor — wired together in `main.py` for two cameras. This is the phase's highest-risk slice because the exact `privratnik.net` auth contract (A1) and ffmpeg pipe-framing (A3) are `[ASSUMED]` and must be validated empirically.

Output: A working capture pipeline that authenticates, decodes frames via ffmpeg, and self-heals on stream/token expiry — with a manual probe script to validate the real auth flow.
</objective>

The exact MJPG pipe-framing is `[ASSUMED]` (A3) — implement a robust byte-buffered parser that accumulates bytes until a complete `0xFFD8..0xFFD9` JPEG is found, then decodes it. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app → privratnik.net | Untrusted external proxy; credentials and tokens cross this boundary |
| ffmpeg subprocess → app | Child process stdout/stderr pipes; must be drained to avoid blocking |
| .env → os.getenv() | Secrets cross from gitignored file into the app |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Information Disclosure | auth.py / logs | high | mitigate | Redact `token=` query param and PHPSESSID in all logged URLs (V7); probe script redacts token/password |
| T-01-04 | Denial of Service (self) | supervisor.py | medium | mitigate | Exponential backoff 1s→…→60s caps retry rate (D-03); interruptible `stop_event.wait()` so shutdown isn't delayed |
| T-01-05 | Resource Exhaustion | stream_client.py / supervisor.py | medium | mitigate | `proc.kill()` + `proc.wait()` in a `finally` on reconnect; drain stderr pipe so it doesn't fill and block (Pitfall 6) |
| T-01-06 | Information Disclosure | config.json / src | high | mitigate | Token appended at request time via `stream_headers_and_url()`, never stored embedded in URL (D-07); test asserts token not in stored URL |
</threat_model>
